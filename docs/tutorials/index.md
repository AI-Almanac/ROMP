# Tutorials

Worked examples that run HCWF end to end on sample data. The notebooks are shown as stored (with their outputs); they are
not executed when the documentation is built. The data they use is in the repository's `demo/` folder, and the notebooks
themselves are the files in `demo/ethiopia/` and `demo/india/` (linked here, not copied).

Each region has two notebooks: a benchmark of forecast models against observations, and the training and use of an onset blend.
